Keyboard Shortcuts

They work while the popup window is open (Alt+G)

User manual

Navigation

↑↓
Select a tab group.
Ctrl+↑↓
Move the selected tab group up or down.
←→
Hide or show the tabs of the selected tab group.
Enter
Switch to the selected tab group.
1–9, a–z
Switch directly to the corresponding tab group.
=
Search tabs.

Tab groups

Insert
Create a tab group.
Ctrl+Insert
Edit the selected tab group.
Delete
Delete the selected tab group.
Ctrl+Delete
Close all tabs in the selected tab group.
Ctrl+Z
Restore the most recently deleted tab group.
/
Reload all tabs in the selected tab group.

Moving tabs

Home
Move the active tab to the selected tab group.
End
Move all tabs, or only the highlighted ones, to the selected tab group.
Ctrl+Home / End
Same as Home or End, then switch to that tab group.
Shift+End
Move the tabs of the selected tab group to a new window.

Clipboard

PageUp
Copy the selected tab group to the clipboard.
Shift+PageUp
Copy all tab groups to the clipboard.
PageDown
Paste tab groups from the clipboard.

Editing form

Ctrl+0–9
Assign the tab group color. Ctrl+9 makes it transparent.
Enter
Save the tab group.

Press F1 in the popup window to open the user manual.
